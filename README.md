#  Python Projects

A collection of **8 basic Python projects** that I’m building to review Python, practice more, and become more comfortable with writing code.

This repository is also my way of starting to share my learning process and projects on GitHub.

##  Goal

My goal is to complete **8 projects in 8 days**.

I’m doing this to:

* Review Python fundamentals
* Practice problem-solving
* Get better at writing Python code
* Build a habit of finishing small projects
* Start sharing my work on GitHub

I’m not expecting the first version of each project to be perfect. I just want to build a simple, working version first and improve it as I learn more.

##  How I’m Working on the Projects

For each project, I first watch the beginning of the course video to understand the idea and requirements.

Then I pause the video and try to complete the project on my own. Once I have a basic version that works, I commit it.

After that, I go back and watch the rest of the video. If I find something that needs to be changed or improved, I update the project and make another commit.

This helps me learn from the course while still giving myself the chance to think and solve problems independently.
